# 3D 资源预览器 v1.3.0

首个 GitHub 公开发布版本。免费、中文、本地离线，Windows 10/11 x64，解压即用。

## 下载哪个附件

- **win64-绿色版.zip**：普通用户下载，完整解压后运行 3D资源预览器.exe，约 153 MB。
- **源码工程.zip**：当前公开提交源码，约 5 MB。
- **开发工程完整包（含git历史）.zip**：继续开发使用，包含经过整理的公开 Git 历史。
- **SHA256.json**：版本、公开提交、运行源码指纹、附件大小和 SHA256。
- **demo-zh.mp4**：65 秒中文功能讲解，1080p / 30 fps，实际软件录制。

GitHub 自动生成的 Source code 附件仅包含源码；普通用户请选择绿色版。

## 功能

批量缩略图、网格/列表、搜索与筛选；GLB/glTF、FBX、OBJ、STL、PLY、DAE 等格式预览；
白膜、线框、法线、平滑/平直、AO、HDRI、自定义环境、动画、剖切、测量、贴图通道和 A/B 对比；
收藏、标签、评分、颜色、重复查找、回收站、GLB/原格式导出、截图、转盘、接触表与 CSV。

## v1.3 改进

- 修复同名模型缓存混用、外部材质更新后旧缩略图、部分删除失败丢记录等问题。
- 文件整理预检依赖与冲突，复制校验后提交模型，保留源共享依赖。
- 设置和资源库原子保存、上一版备份、资源库导入合并。
- 暂停后台缩略图时仍可导出 GLB，切换目录保留导出任务。
- 升级 Electron 44.5.1，加强隔离沙箱、IPC、真实路径校验和异常日志处理。

## 已验证

104 项单元测试、93 步查看器、24 项资源库、16 项故障检查及 7 项真实 EXE 检查通过。
1,645 模型素材库的可见缩略图滚到底约 0.8 秒、回顶部约 0.5 秒；这是本机低面数素材的视口测试。
公开源码已重新安装、类型检查、单元测试和构建，其运行源码指纹与已验收绿色版一致。

`.blend` 3D 交互需要兼容版本 Blender；MAX、C4D 等私有格式只列出。
尚未做多机长期稳定性测试，发布包尚未代码签名。升级时关闭程序，再复制旧版 data 到新版 exe 同级。

完整变更与验证范围见 CHANGELOG.md、docs/RELEASE_VALIDATION.md；开发见 HANDOFF.md。
