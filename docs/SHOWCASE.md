# 功能演示说明

主页截图、动图和短片使用 3D 资源预览器 v1.3.0 的实际界面录制，示例模型来自 Kenney Nature Kit（CC0）。
录制时将本机目录路径替换为示例素材名称；模型、格式筛选、显示方式、HDRI、剖切与 A/B 对比均来自软件真实功能。

## 先展示支持的格式与 Blender 预览

混合目录包含 `.blend`、DAE、FBX、GLB、OBJ、STL 六种格式，共 24 个模型；OBJ 材质库作为伴生文件隐藏。
Blender 示例文件由 Blender 4.5 从 Kenney 的 CC0 glTF 模型保存生成，使用后台保存，不含可用内嵌预览图。
录屏中的 `.blend` 缩略图和交互查看来自软件调用本机 Blender 转换的实际结果；已检查转换 GLB 含几何体。

片段顺序：多格式与 Blender 预览开场；混合格式素材墙；筛选 `.blend` 并双击进入三维查看；
材质、白膜、法线与线框；AO / 阴影和 HDRI 环境；剖切；A/B 相机联动对比。

## 制作与验证

修订短片约 88 秒，1920×1080，30 fps，H.264 + AAC。由 HyperFrames 0.8.111 编排，GSAP 3.14.2 处理标题动效，FFmpeg 编码。
讲解使用本机 Windows 的 Microsoft Yaoyao 中文语音合成，功能标题和说明与片段对应。
不包含真人配音、不使用背景音乐，字体文件和录制时使用的模型文件不在程序包或公开源码中分发。

视频工程通过 HyperFrames 的静态、运行、布局和对比度检查；实际 MP4 检查分辨率、帧率、时长和音频流。
视频和动图用于展示，不替代每一种文件格式与复杂模型的兼容性验证，具体范围见 RELEASE_VALIDATION.md。

演示视频在 GitHub v1.3.0 Release，原始录制工程保存在维护者本机的临时演示目录。
