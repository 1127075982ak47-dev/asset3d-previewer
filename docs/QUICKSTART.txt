3D 资源预览器 v1.3.0
免费软件 · 中文 · 本地离线 · Windows 10/11 x64

一、开始使用
1. 把绿色版压缩包完整解压到可写目录，再双击 3D资源预览器.exe。
2. 按 Ctrl+O 选择素材文件夹，或者把文件夹拖到 exe 上。
3. 双击模型缩略图进入查看器；左键旋转，滚轮缩放，Esc 返回。
4. 查看器右侧可以切换白膜、线框、法线、平滑/平直、AO、HDRI、剖切和测量。
5. F1 查看全部快捷键。设置中可以切换浅色/深色、配置 Blender、调整性能。

二、常用操作
Ctrl+F 搜索；Ctrl+L 切换列表；Ctrl+D 收藏；数字 0–5 评分。
Ctrl/Shift+点击多选；F2 重命名；Delete 移到回收站；F5 重新扫描。
选择两个模型可以并排对比。批量操作条可导出 GLB、原格式、接触表和 CSV。
设置 → 系统 → 备份资源库，可以保存收藏、标签、评分和颜色记录。
导入备份会合并有效记录，并保留之前的备份文件。

三、性能
默认启用 GPU 硬件加速；关闭后将使用软件渲染，通常更慢。
GPU 选项修改后需要重启。出现软件渲染提示时请检查该设置。
查看器打开时暂停后台缩略图；静止场景按需重绘；AO 使用较低渲染像素比。
很大的模型可以关闭 AO、线框覆盖、阴影，或者降低缩略图并发数量。

四、格式与依赖
可预览 GLB/glTF、FBX、OBJ、STL、PLY、DAE、USDZ、3MF、3DS、WRL、点云等。
.blend 的静态内嵌缩略图无需 Blender；3D 交互和 GLB 转换需要兼容版本的 Blender。
MAX、C4D、SKP、STEP 等私有或 CAD 格式只列出，不能直接预览。
预览或导出失败时，可右键查看原因、检查依赖、定位文件或重新生成缩略图。
原格式导出/移动会携带已识别依赖，复制校验后才提交模型，遇到冲突会保留源文件。
移动只删除源模型，源共享贴图、bin、mtl 等保留，供同目录其他模型继续使用。
重命名不改依赖文件名，FBX 内部对旧 .fbm 目录的引用继续有效。
引用父目录的 glTF/OBJ/DAE 等应导出 GLB，或在资源管理器中整体复制素材文件夹。
私有格式以及非标准资源路径的依赖可能无法识别，请整体复制资源目录。

五、升级与迁移
关闭旧版，将新版解压到一个新目录，确认可以正常打开。
需要沿用设置/收藏/自定义 HDRI 时，关闭新版后把旧版 data 文件夹复制到新版 exe 同级。
素材路径相同时资源库记录会沿用；换盘符或目录后，旧绝对路径记录需要重新关联。
v1.3 调整了缓存身份，同名素材不再串图；旧缩略图会自动重建，无需删除收藏。
不要在压缩包内直接运行，不要只复制 exe；其余运行文件必须一起保留。
数据在 exe 同级 data 下；目录不可写时会回退到用户数据目录，具体位置见「关于」。
data/thumbs 是可重建缓存；library.json 是资源库；settings.json 是设置；hdri 是自定义环境。
JSON 数据采用临时写入和上一版 .bak 备份。排查问题可以从「关于」打开日志目录。
