## 验证范围

- 大库结果为本机低面数素材、视口优先出图的短测试，不代表全部 1,645 个模型均在该耗时内渲染完成。
- 本轮没有在其他实体电脑做长期稳定性测试，也没有逐个验证格式表中每一种格式的全部变体。
- 拖出检查验证正确文件清单；向 Blender/Unity/UE 的真实系统拖拽仍需要实际鼠标操作。
- 原格式依赖解析覆盖 GLB/glTF、OBJ/MTL、DAE，以及 FBX 等常见相邻贴图目录；非标准和私有格式依赖可能需要整体复制目录。
- 尚未代码签名。软件使用本地文件，保持免费，不含账号、遥测和在线服务。

三个发布包从同一 Git 提交导出，发布清单包含 SHA256。开发包不含远端地址、用户身份、hooks、缓存和 node_modules。
