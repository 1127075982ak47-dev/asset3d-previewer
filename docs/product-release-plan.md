# v1.3.0 产品交付范围

本轮目标：完成资源浏览、查看、整理、导出、数据保存与换机开发的完整流程。

- 文件移动预检依赖冲突，依赖复制失败时回滚；保留源目录共享依赖。
- 删除结果按完整路径返回，仅成功删除的文件清理资源库记录。
- 缓存纳入资源位置、源文件版本与外部贴图/材质版本。
- JSON 原子保存、合法版本备份与恢复，写入失败明确提示。
- 自定义协议校验真实路径；主窗口与 worker 分离权限；IPC 校验来源及参数。
- GLB 导出在查看器打开和切换目录时仍能完成。
- 真实 Electron 验收、故障回归测试、绿色版烟雾测试、源包与完整开发包。

产品约束：中文、完全免费、离线工作、浅色玻璃主题并保留深色、Windows x64 绿色版。

执行结果：上述功能与实际运行门禁完成，详见 RELEASE_VALIDATION.md。
